| ไฟล์ทดสอบ | จำนวน Test | ครอบคลุม |

| `attendance/late.test.ts` | 26 | คำนวณสถานะสาย/ขาด 2 ระดับ ทั้งกะปกติและกะข้ามเที่ยงคืน (`crossesMidnight`) |

| `leave/vacation-policy.test.ts` | 15 | สูตรคำนวณสิทธิ์พักร้อนตามอายุงาน, การให้โบนัส/รีเซ็ตประจำปี |

### ตัวอย่าง Test Case จริง (จาก checkin-rules.test.ts)

| # | สถานการณ์ (Input) | ผลที่คาดหวัง (Expected Output) |
|---|---|---|
| 1 | พนักงานเช็คอินตรงเวลากะที่มีวันนี้ | จับคู่กะวันนี้, `fromPreviousDay = false` |
| 2 | กะข้ามเที่ยงคืน (22:00–06:00) เช็คอินเวลา 02:00 (หลังเที่ยงคืนแล้ว) | จับคู่กะของ "เมื่อวาน" ที่ยังไม่จบ, `fromPreviousDay = true` |
| 3 | ไม่มีกะไหนตรงเวลาเลย | fallback เลือกกะที่ใกล้เคียงที่สุด |
| 4 | เช็คอินในเวลาที่ยังไม่มีกะไหนเข้าเงื่อนไข (นอกทุกช่วง) | คืนค่า `null` — เช็คอินไม่ได้ |
| 5 | ระยะห่างจากสาขา ≤ รัศมี | `isOutsideArea = false` |
| 6 | ระยะห่างเกินรัศมี, สาขาตั้ง `geo_mode = WARN` | เช็คอินผ่าน, `blocked = false, isOutsideArea = true` |
| 7 | ระยะห่างเกินรัศมี, สาขาตั้ง `geo_mode = BLOCK` | `blocked = true` — เช็คอินไม่ผ่าน |

## 2. Manual QA Test Cases (สถานการณ์สำคัญที่ต้องทดสอบด้วยตา)

| # | หมวด | สถานการณ์ | ผลที่คาดหวัง |
|---|---|---|---|
| M-01 | เช็คอิน | พนักงานเช็คอินผ่าน LIFF โดยไม่อนุญาต GPS | เช็คอินสำเร็จ, บันทึก `gps_lat/lng = null` ไม่บล็อก |
| M-02 | เช็คอิน | สแกน QR Code นอกพื้นที่สาขา (geo_mode ของสาขาตั้งเป็น WARN) | ถูกบล็อก — QR ใช้กฎ BLOCK เสมอไม่ว่าสาขาตั้งอะไรไว้ |
| M-03 | วันลา | ยื่นคำขอลาวันที่มีคนตำแหน่งเดียวกันลาไว้แล้ว | สร้างคำขอสำเร็จ พร้อม badge "ชนกัน" ให้แอดมินเห็นตอนอนุมัติ ไม่ถูกบล็อก |
| M-04 | วันหยุด | จองวันหยุดหลังพ้น deadline ของรอบเดือนนั้น | จองไม่ได้ — ระบบปิดรอบอัตโนมัติ |
| M-05 | Magic Login | กดลิงก์แจ้งเตือน LINE ที่เคยใช้ไปแล้ว (token ถูก consume แล้ว) แต่เครื่องนั้นยัง login ค้างอยู่ | ระบบ peek next_path จาก token เดิมแล้วพาไปหน้าที่ตั้งใจ ไม่ต้อง login ใหม่ |
| M-06 | Magic Login | กดลิงก์เดิมซ้ำในอุปกรณ์ที่ไม่เคย login มาก่อน | แสดง "ลิงก์หมดอายุหรือถูกใช้ไปแล้ว" พร้อมปุ่มไปหน้า login ปกติ |
| M-07 | ลาออก | แอดมินอนุมัติคำขอลาออก | สถานะพนักงานเปลี่ยนเป็น RESIGNED ทันที, เช็คอิน/เข้า LIFF ไม่ได้อีก |
| M-08 | เอกสาร HR | สร้างสลิปเงินเดือนในระบบ แล้วภายหลังพนักงานย้ายสาขา | เอกสารเก่ายังแสดงข้อมูลสาขาเดิม ณ วันที่ออก (ใช้ snapshot ไม่ join ข้อมูลสด) |
| M-09 | นโยบายพักร้อน | พนักงานที่ตำแหน่งยังไม่ได้ตั้งค่าสิทธิ์พักร้อนตามอายุงาน | ไม่ได้รับผลกระทบใดๆ จาก cron โบนัส/รีเซ็ต (backward compatible) |
| M-10 | รายงาน | เปิดรายงานการส่งข้อความไลน์ก่อนวันที่เริ่มบันทึก log | แสดงข้อความอธิบายว่าไม่มีข้อมูลย้อนหลัง แทนที่จะโชว์ตารางว่างเฉยๆ |
| M-11 | RBAC | ผู้ใช้บทบาท EXECUTIVE พยายามกดอนุมัติคำขอลา | ปุ่มอนุมัติถูกซ่อน/ปิดใช้งานที่ frontend และ backend ปฏิเสธคำขอ (403) ถ้ายิง API ตรง |
| M-12 | Multi-tenant | ผู้ใช้ของ tenant A พยายามเรียกดูข้อมูลพนักงานของ tenant B ผ่าน ID ตรงๆ | ไม่พบข้อมูล (query กรอง `tenant_id` ทุกครั้ง) |

## 3. Responsive / Cross-device Testing

- ทุกหน้าในเว็บแอดมินต้องทดสอบที่ breakpoint มือถือ (< 768px) และเดสก์ท็อป
- หน้ารายการ (list) ที่มีมุมมองการ์ด/ตารางคู่กัน ต้องทดสอบทั้งสองมุมมอง
- แอป LIFF ต้องทดสอบภายในเว็บวิวจริงของแอป LINE (ไม่ใช่แค่เบราว์เซอร์ปกติ) เพราะพฤติกรรม LIFF SDK (auto-login, geolocation permission) ต่างจากเบราว์เซอร์ทั่วไป
