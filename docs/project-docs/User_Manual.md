# User Manual

คู่มือการใช้งานสำหรับผู้ใช้ 2 กลุ่มหลัก: **ฝ่าย HR/แอดมิน** (เว็บแอป) และ **พนักงาน** (แอป LINE)

---

## ส่วนที่ 1 — คู่มือแอดมิน (เว็บแอป)

### 1.1 การเข้าสู่ระบบ

- เข้าเว็บแอดมิน แล้วกรอก username (อีเมล) และรหัสผ่าน
- หากกดลิงก์จากการแจ้งเตือน LINE ระบบจะพาเข้าสู่ระบบอัตโนมัติ (auto-login) โดยไม่ต้องกรอกรหัสผ่าน และพาไปหน้าที่เกี่ยวข้องกับการแจ้งเตือนนั้นโดยตรง
- เปลี่ยนรหัสผ่าน/แก้ชื่อที่แสดงได้จากเมนูโปรไฟล์มุมขวาบน (Topbar)

### 1.2 เมนูหลัก (Sidebar)

| หมวด | เมนูย่อย |
|---|---|
| **ภาพรวม** | แดชบอร์ด — KPI สรุปตามช่วงวันที่ |
| **ข้อมูล** | สาขา, พนักงาน, Master Data |
| **การกระทำ** | เช็คอิน (เช็คอินวันนี้ + ตารางกะ), การลาและวันหยุด, เช็คอินนอกสถานที่, OT, คำขอลาออก, ขอเอกสาร HR, ประกาศ |
| **รายงาน** | รายงานผู้บริหาร, พนักงาน, การเช็คอิน, สาขา, วันหยุด, วันลา, การส่งข้อความไลน์ |
| **ตั้งค่า** | ข้อมูลบริษัท, ผู้ใช้งานเว็บ, การแจ้งเตือน |

### 1.3 จัดการพนักงาน

1. ไปที่ **ข้อมูล → พนักงาน**
2. กด "เพิ่มพนักงาน" กรอกข้อมูล (ชื่อ, สาขา, ตำแหน่ง, เบอร์โทร) — พนักงานผูกบัญชี LINE เองครั้งแรกที่เข้าแอป LIFF
3. คลิกชื่อพนักงานเพื่อดู/แก้ไขรายละเอียด, มอบสิทธิ์เข้าเว็บแอดมิน, จัดการเอกสารประจำตัว/ทดลองงาน
4. สลับมุมมองการ์ด/ตารางได้ที่ปุ่มมุมขวาบนของรายการ, ใช้ช่องค้นหา/ตัวกรองผังองค์กรเพื่อจำกัดรายการ

### 1.4 จัดการสาขาและกะ

- **สาขา**: ตั้งพิกัด GPS + รัศมี + โหมดตรวจสอบตำแหน่ง (เตือน/บล็อก) ต่อสาขา, ดู QR Code สำหรับให้พนักงานสแกนเช็คอิน
- **จัดการกะ** (แท็บในหน้าสาขา): สร้างกะ ตั้งเวลาเข้า-ออก เกณฑ์สาย/ขาด ค่าปรับ — ระบบเตือนอัตโนมัติถ้าตั้งเป็นกะข้ามเที่ยงคืน

### 1.5 อนุมัติคำขอ (ลา / OT / ลาออก / วันหยุด / เอกสาร)

- ทุกคำขอใหม่ส่งแจ้งเตือนทาง LINE ถึงแอดมิน/หัวหน้าแผนกทันที กดลิงก์ในข้อความเพื่อเข้าหน้าอนุมัติได้เลยโดยไม่ต้อง login ใหม่
- หน้ารายการคำขอมีปุ่ม "อนุมัติ"/"ปฏิเสธ" พร้อมช่องกรอกเหตุผล (กรณีปฏิเสธ)
- คำขอลาที่ชนกับคนตำแหน่งเดียวกัน จะมีสัญลักษณ์เตือนให้เลือกว่าจะหักโควต้าประเภทไหนตอนอนุมัติ

### 1.6 จองวันหยุดประจำเดือน (ฝั่งแอดมิน)

1. ไปที่ **การลาและวันหยุด → จองวันหยุดประจำเดือน**
2. เปิดรอบจองต่อสาขา ตั้ง deadline และหมายเหตุถึงพนักงาน — ระบบแจ้งเตือนพนักงานในสาขานั้นทาง LINE ทันที
3. อนุมัติคำขอทีละรายการหรืออนุมัติทั้งหมดพร้อมกันได้

### 1.7 รายงาน

- ทุกหมวดรายงานเลือกเดือนได้ด้วยปุ่มลูกศร ‹ › และสลับมุมมองการ์ด/ตารางได้
- **รายงานผู้บริหาร** สรุปงานค้างที่ต้องอนุมัติทั้งหมด (ลา/OT/ลาออก/เอกสาร) พร้อมทางลัดไปหน้าที่เกี่ยวข้อง
- **รายงานการส่งข้อความไลน์** แสดงประวัติการแจ้งเตือนทุกครั้ง สำเร็จ/ล้มเหลว (มีข้อมูลตั้งแต่วันที่ระบบเริ่มบันทึก log เป็นต้นไป)

### 1.8 ตั้งค่า

- แก้ไขข้อมูลบริษัท, ชื่อผู้ลงนามท้ายเอกสาร HR
- จัดการบัญชีผู้ใช้งานเว็บแอดมิน (เพิ่ม/ลบสิทธิ์)
- เปิด/ปิดประเภทการแจ้งเตือน LINE แต่ละแบบ

## ส่วนที่ 2 — คู่มือพนักงาน (แอป LINE)

### 2.1 การเข้าใช้งานครั้งแรก

- เปิดลิงก์/เมนู LIFF ของบริษัทในแอป LINE — ระบบผูกบัญชีให้อัตโนมัติจาก LINE ID (ไม่ต้องสมัคร/ตั้งรหัสผ่าน)

### 2.2 การเช็คอิน-เช็คเอาท์

1. เปิดหน้า "เช็คอิน" ในแอป
2. กดเช็คอิน — ระบบตรวจตำแหน่ง GPS (ถ้าอนุญาต) และจับคู่กะที่ตรงกับเวลาปัจจุบันอัตโนมัติ
3. หากอยู่นอกพื้นที่สาขา ระบบจะเตือนหรือบล็อกตามที่สาขาตั้งค่าไว้
4. เช็คเอาท์เมื่อเลิกงานในหน้าเดียวกัน
5. สามารถสแกน QR Code หน้าสาขาเพื่อเช็คอินแทนได้เช่นกัน

### 2.3 ขอลา

1. ไปที่แท็บ "วันลา" เลือกประเภทลา ระบุวันที่/ช่วงเวลา และเหตุผล
2. ระบบแสดงจำนวนวันคงเหลือให้ดูก่อนยื่น
3. ติดตามสถานะ (รอพิจารณา/อนุมัติ/ไม่อนุมัติ) ได้ในหน้าเดียวกัน

### 2.4 จองวันหยุดประจำเดือน

- เมื่อแอดมินเปิดรอบจอง จะมีการแจ้งเตือนทาง LINE พร้อมลิงก์พาไปหน้าจองของเดือนที่เปิดโดยตรง
- เลือกวันหยุดตามโหมดที่บริษัทกำหนด (เลือกทีละวัน หรือต้องเลือกครบทุกสัปดาห์ในเดือนนั้น)
- ดูปฏิทินรวมของเพื่อนร่วมงานที่จองไว้แล้วในวันเดียวกันได้

### 2.5 ขอ OT / ขอเอกสาร HR / ยื่นลาออก

- ทำได้จากเมนูที่เกี่ยวข้องในแอป กรอกรายละเอียด แล้วรอการอนุมัติจากแอดมิน — ผลลัพธ์แจ้งเตือนกลับทาง LINE เสมอ

### 2.6 สลับไปเว็บแอดมิน (เฉพาะผู้มีสิทธิ์)

- หากบัญชีถูกผูกกับสิทธิ์แอดมิน จะมีปุ่ม "สลับไปเว็บแอดมิน" ในหน้าโปรไฟล์ กดแล้วเข้าเว็บแอดมินอัตโนมัติโดยไม่ต้อง login ซ้ำ

### 2.7 แจ้งปัญหาการใช้งาน

- หากเข้าแอปไม่ได้เลย (เช่น error ขณะโหลด) มีช่องทางแจ้งปัญหาที่ส่งตรงถึงแอดมินทาง LINE ได้ทันทีโดยไม่ต้อง login
