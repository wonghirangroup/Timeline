# User Manual

คู่มือการใช้งานสำหรับผู้ใช้ 2 กลุ่มหลัก: **ฝ่าย HR/แอดมิน** (เว็บแอป) และ **พนักงาน** (แอป LINE)

---

## ส่วนที่ 1 — คู่มือแอดมิน (เว็บแอป)

### 1.1 การเข้าสู่ระบบ

- เข้าเว็บแอดมิน แล้วกรอก username (อีเมล) และรหัสผ่าน
- หากกดลิงก์จากการแจ้งเตือน LINE ระบบจะพาเข้าสู่ระบบอัตโนมัติ (auto-login) โดยไม่ต้องกรอกรหัสผ่าน และพาไปหน้าที่เกี่ยวข้องกับการแจ้งเตือนนั้นโดยตรง
- เปลี่ยนรหัสผ่าน/แก้ชื่อที่แสดงได้จากเมนูโปรไฟล์มุมขวาบน (Topbar)

### 1.2 เมนูหลัก (Sidebar)

| หมวด | เมนูย่อย |
|---|---|
| **ภาพรวม** | แดชบอร์ด — KPI สรุปตามช่วงวันที่ |
| **ข้อมูล** | สาขา, พนักงาน, Master Data |
| **การกระทำ** | เช็คอิน (เช็คอินวันนี้ + ตารางกะ), การลาและวันหยุด, เช็คอินนอกสถานที่, OT, คำขอลาออก, ขอเอกสาร HR, ประกาศ |
| **รายงาน** | รายงานผู้บริหาร, พนักงาน, การเช็คอิน, สาขา, วันหยุด, วันลา, การส่งข้อความไลน์ |
| **ตั้งค่า** | ข้อมูลบริษัท, ผู้ใช้งานเว็บ, การแจ้งเตือน |

### 1.3 จัดการพนักงาน

1. ไปที่ **ข้อมูล → พนักงาน**
2. กด "เพิ่มพนักงาน" กรอกข้อมูล (ชื่อ, สาขา, ตำแหน่ง, เบอร์โทร) — พนักงานผูกบัญชี LINE เองครั้งแรกที่เข้าแอป LIFF
3. คลิกชื่อพนักงานเพื่อดู/แก้ไขรายละเอียด, มอบสิทธิ์เข้าเว็บแอดมิน, จัดการเอกสารประจำตัว/ทดลองงาน
4. สลับมุมมองการ์ด/ตารางได้ที่ปุ่มมุมขวาบนของรายการ, ใช้ช่องค้นหา/ตัวกรองผังองค์กรเพื่อจำกัดรายการ

### 1.4 จัดการสาขาและกะ

- **สาขา**: ตั้งพิกัด GPS + รัศมี + โหมดตรวจสอบตำแหน่ง (เตือน/บล็อก) ต่อสาขา, ดู QR Code สำหรับให้พนักงานสแกนเช็คอิน
- **จัดการกะ** (แท็บในหน้าสาขา): สร้างกะ ตั้งเวลาเข้า-ออก เกณฑ์สาย/ขาด ค่าปรับ — ระบบเตือนอัตโนมัติถ้าตั้งเป็นกะข้ามเที่ยงคืน

### 1.5 อนุมัติคำขอ (ลา / OT / ลาออก / วันหยุด / เอกสาร)

- ทุกคำขอใหม่ส่งแจ้งเตือนทาง LINE ถึงแอดมิน/หัวหน้าแผนกทันที กดลิงก์ในข้อความเพื่อเข้าหน้าอนุมัติได้เลยโดยไม่ต้อง login ใหม่
- หน้ารายการคำขอมีปุ่ม "อนุมัติ"/"ปฏิเสธ" พร้อมช่องกรอกเหตุผล (กรณีปฏิเสธ)
- คำขอลาที่ชนกับคนตำแหน่งเดียวกัน จะมีสัญลักษณ์เตือนให้เลือกว่าจะหักโควต้าประเภทไหนตอนอนุมัติ

### 1.6 จองวันหยุดประจำเดือน (ฝั่งแอดมิน)

1. ไปที่ **การลาและวันหยุด → จองวันหยุดประจำเดือน**
2. เปิดรอบจองต่อสาขา ตั้ง deadline และหมายเหตุถึงพนักงาน — ระบบแจ้งเตือนพนักงานในสาขานั้นทาง LINE ทันที
3. อนุมัติคำขอทีละรายการหรืออนุมัติทั้งหมดพร้อมกันได้

### 1.7 รายงาน

- ทุกหมวดรายงานเลือกเดือนได้ด้วยปุ่มลูกศร ‹ › และสลับมุมมองการ์ด/ตารางได้
- **รายงานผู้บริหาร** สรุปงานค้างที่ต้องอนุมัติทั้งหมด (ลา/OT/ลาออก/เอกสาร) พร้อมทางลัดไปหน้าที่เกี่ยวข้อง
- **รายงานการส่งข้อความไลน์** แสดงประวัติการแจ้งเตือนทุกครั้ง สำเร็จ/ล้มเหลว (มีข้อมูลตั้งแต่วันที่ระบบเริ่มบันทึก log เป็นต้นไป)

### 1.8 ตั้งค่า

- แก้ไขข้อมูลบริษัท, ชื่อผู้ลงนามท้ายเอกสาร HR
- จัดการบัญชีผู้ใช้งานเว็บแอดมิน (เพิ่ม/ลบสิทธิ์)
- เปิด/ปิดประเภทการแจ้งเตือน LINE แต่ละแบบ

## ส่วนที่ 2 — คู่มือพนักงาน (แอป LINE)

เมนูล่าง 4 ปุ่ม: **เช็คอิน · ประวัติ · วันลา · โปรไฟล์** — OT, ขอเอกสาร HR, หนังสือเตือน, ส่งความคิดเห็น, ยื่นลาออก อยู่ที่ โปรไฟล์ → เมนูอื่นๆ

### 2.1 การเข้าใช้งานครั้งแรก (ผูกบัญชี LINE)

1. เปิดแอปจาก LINE — ครั้งแรกจะเห็นคู่มือผูกบัญชี 6 ขั้นตอน
2. เลือกชื่อของคุณจากรายการ (ค้นหาด้วยชื่อ/ชื่อเล่น/สาขาได้)
3. กรอก **รหัสพนักงาน** เพื่อยืนยัน (เช่น 69-01-003) แล้วกด "ใช่ นี่คือฉัน — ผูกบัญชี"
4. เลือกอัปโหลดรูปโปรไฟล์ หรือ "ไว้ทีหลัง" แล้วเข้าสู่หน้าเช็คอิน
- ไม่พบชื่อ / ผูก LINE อื่นไปแล้ว → ติดต่อ HR · กรอกรหัสผิดหลายครั้งจะถูกล็อกชั่วคราว

### 2.2 การเช็คอิน-เช็คเอาท์

1. เปิดหน้า "เช็คอิน" กดปุ่มวงกลมใหญ่ แล้ว **สแกน QR Code ที่ติดไว้หน้าสาขา** (สแกนด้วยกล้อง หรือเลือกรูป QR จากเครื่อง)
2. ตรวจข้อมูล (สาขา กะ เวลา) แล้วกด "ยืนยันเช็คอิน" — ระบบตรวจจับกะจากเวลาที่สแกนอัตโนมัติ
3. ผลที่เห็น: มาทำงานปกติ / มาสายระดับ 1 / มาสายระดับ 2 / นับเป็นวันขาด พร้อมนาทีที่สายและค่าปรับ (ถ้ามี)
4. เลิกงานกดปุ่มเดิม (เปลี่ยนเป็น "เช็คเอาต์") แล้วสแกน QR เดิมอีกครั้ง
5. เช็คอินไม่ได้เมื่อ ไม่ได้สังกัดสาขานั้น, QR หมดอายุ/ถูกดัดแปลง (ขอ QR ใหม่จากแอดมิน) หรืออยู่นอกพื้นที่ (ถ้าสาขาตั้งบล็อก)
6. ค่าปรับมาสายตามกะ — แอดมินตั้ง "ไม่ปรับเงิน" ได้ระดับกลุ่ม/ฝ่าย/แผนก/ตำแหน่ง/สาขา/รายคน (ไม่กระทบค่าปรับขาดงาน)
7. **เช็คอินนอกสถานที่** (เฉพาะคนที่แอดมินเปิดสิทธิ์): ปักหมุดเช็คอิน/เช็คเอาต์บนแผนที่ สำหรับไปประชุม/งาน Event

### 2.3 ประวัติ

- เลือกเดือน แล้วดู 4 แท็บ: เช็คชื่อ · วันลา · วันหยุด · นอกสถานที่ (ตรงเวลา/มาสาย/ขาดงาน/นอกพื้นที่)

### 2.4 วันลา (3 แท็บ: ปฏิทิน · จองหยุด · ขอลา)

**ปฏิทิน** — สลับ "ปฏิทินรวม" (เห็นเพื่อนร่วมงาน) / "วันหยุดของฉัน" · สีเขียว = เพื่อนร่วมงานหยุด, สีส้ม = เพื่อนร่วมงานลา (จุดวงกลมแสดงจำนวนคน กดวันที่ดูรายชื่อ) · ขอสลับวันหยุดกับเพื่อนได้ (เพื่อนต้องกดยอมรับ)

**จองหยุด** — เมื่อแอดมินเปิดรอบจะมีแจ้งเตือน LINE พร้อมลิงก์พาไปหน้าจองของเดือนนั้น
- เลือกวันหยุดตามโหมดบริษัท (รายสัปดาห์ / รวมทั้งเดือน) แล้วส่งคำขอ รอผู้จัดการพิจารณา
- ยกเลิกเองได้เฉพาะวันที่ "รอพิจารณา" — วันที่อนุมัติแล้วต้อง "ขอเปลี่ยนวัน" ให้แอดมินอนุมัติ
- เดือนที่ปิดจองแล้ว: ถ้ามีวันจองของตัวเองและโควต้าเหลือ ยังเพิ่มวันจองได้
- ใช้โควต้าพักร้อนจากหน้านี้ได้ (ไม่มีตัวเลือก "ชดเชย")
- วันหยุด + พักร้อนรวมกันมีเพดานต่อเดือน (ปัจจุบัน 10 วัน) — เกินยังยื่นได้ แอดมินจะเห็นป้ายเตือน

**ขอลา** — เลือกประเภทการลา (เห็นวันลาคงเหลือ) → ช่วงการลา (เต็มวัน/ครึ่งเช้า/ครึ่งบ่าย/ระบุเวลา) → วันที่ → เหตุผล (บังคับ) → ส่งคำขอลา
- ยื่นได้แม้โควต้าหมดหรือยังไม่มีโควต้า — ถ้าอนุมัติ ยอดคงเหลือจะติดลบ
- ถ้าเพื่อนตำแหน่งเดียวกันหยุด/ลาวันนั้น ระบบเตือน และอาจมีค่าหักต่อวัน (เลือกวันอื่นเพื่อเลี่ยง)
- ติดตามสถานะ (รอพิจารณา/อนุมัติแล้ว/ไม่อนุมัติ) ในหน้าเดียวกัน และแจ้งผลทาง LINE

### 2.5 โปรไฟล์ → เมนูอื่นๆ

- **รายการ OT** — แท็บประวัติ / ขอ OT (วันที่ เวลาเริ่ม-สิ้นสุด หมายเหตุ) รอผู้จัดการอนุมัติ
- **ขอเอกสาร HR** — สลีปเงินเดือน / หนังสือรับรองเงินเดือน / หนังสือรับรองการทำงาน / อื่นๆ (แสดงเมื่อบริษัทเปิดฟีเจอร์)
- **หนังสือเตือน** — ดูหนังสือเตือนจาก HR แล้วกด "รับทราบ" (แสดงเมื่อบริษัทเปิดฟีเจอร์)
- **ส่งความคิดเห็น** — เลือกหัวข้อ พิมพ์ ≥ 10 ตัวอักษร ส่งแบบไม่ระบุตัวตน
- **ยื่นลาออก** — ระบุวันทำงานสุดท้ายและเหตุผล รอผู้ดูแลอนุมัติ (ยังใช้งานได้ปกติจนถึงวันทำงานสุดท้าย) (แสดงเมื่อบริษัทเปิดฟีเจอร์)

### 2.6 โปรไฟล์ และสลับไปเว็บแอดมิน

- เปลี่ยนรูปโปรไฟล์ที่ไอคอนกล้อง · ดูสิทธิ์วันพักร้อนตามอายุงาน · ปุ่ม "เปลี่ยนบัญชี LINE" ท้ายหน้า
- บัญชีที่มีสิทธิ์แอดมินจะมีปุ่ม "สลับไปเว็บแอดมิน" เข้าเว็บโดยไม่ต้อง login ซ้ำ

### 2.7 แจ้งปัญหาการใช้งาน

- หากเข้าแอปไม่ได้ (เช่น Network Error) กด "ลองใหม่" ก่อน ถ้ายังไม่ได้ใช้ปุ่ม "แจ้งปัญหาให้แอดมิน" ส่งตรงถึงแอดมินทาง LINE โดยไม่ต้อง login
