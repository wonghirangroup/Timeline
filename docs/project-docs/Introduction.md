# Introduction

## ความเป็นมาของโครงการ

ธุรกิจ SME ไทยจำนวนมากยังจัดการเรื่องเวลาทำงาน การเข้า-ออกงาน และวันลาของพนักงานด้วยวิธีแบบ manual — สมุดลงเวลา, กลุ่มไลน์, หรือสเปรดชีตที่ต้องกรอกมือ ทำให้ HR/หัวหน้างานเสียเวลาสรุปข้อมูลย้อนหลัง คำนวณวันสาย/ขาด/ค่าปรับผิดพลาดได้ง่าย และไม่มีระบบอนุมัติคำขอ (ลา/OT/วันหยุด) ที่ตรวจสอบย้อนหลังได้

**TimeLine HR** ถูกพัฒนาขึ้นเพื่อแก้ปัญหานี้ — เป็นระบบจัดการเวลาทำงานและการลาแบบ SaaS (Software as a Service) หลายผู้เช่า (multi-tenant) ที่พนักงานเช็คอิน-เช็คเอาท์ผ่านแอปมือถือ (LINE LIFF) โดยอิงตำแหน่ง GPS และกะการทำงานของตัวเอง ขณะที่ฝ่าย HR/ผู้จัดการดูภาพรวม อนุมัติคำขอ และออกรายงานผ่านเว็บแอปแอดมิน

## วัตถุประสงค์ของโครงการ

1. ลดภาระงานเอกสาร/สเปรดชีตของฝ่าย HR ในการติดตามเวลาทำงาน วันลา และวันหยุดของพนักงาน
2. ให้พนักงานเช็คอิน-เช็คเอาท์ได้เองผ่านมือถือ โดยระบบตรวจสอบตำแหน่ง/เวลาตามกะอัตโนมัติ
3. ให้ผู้บริหาร/HR อนุมัติคำขอ (ลา, OT, ลาออก, จองวันหยุด, ขอเอกสาร) ผ่านเว็บแอปเดียว พร้อมแจ้งเตือนทาง LINE แบบเรียลไทม์
4. รองรับโครงสร้างองค์กรที่ซับซ้อน (หลายสาขา, หลายฝ่าย/แผนก/ตำแหน่ง) พร้อมนโยบาย (สิทธิ์จองวันหยุด, โควต้าลา) ที่ตั้งค่าได้เป็นลำดับชั้น (cascade)
5. ให้ผู้ให้บริการ (Vendor) ขายระบบเป็น SaaS ให้ลูกค้าหลายบริษัท (multi-tenant) พร้อมระบบแพ็กเกจ/บิลลิ่งของตัวเอง

## ขอบเขตของเอกสารชุดนี้

เอกสารในโฟลเดอร์ `docs/project-docs/` นี้ เป็นชุดเอกสารประกอบโครงการตามรูปแบบมาตรฐานงานวิศวกรรมซอฟต์แวร์ (SRS, ER Diagram, Class Diagram, Data Dictionary, Flowchart, Test Cases, User Manual ฯลฯ) เขียนขึ้นจากสถานะจริงของโค้ด ณ วันที่จัดทำเอกสาร ไม่ใช่เอกสารออกแบบล่วงหน้า (design-first) — ระบบพัฒนาและ deploy ใช้งานจริงแล้ว เอกสารชุดนี้จึงทำหน้าที่สรุป/บันทึกสถาปัตยกรรมและพฤติกรรมของระบบที่มีอยู่จริง เพื่อใช้อ้างอิงและส่งมอบ

สำหรับเอกสารเชิงลึกด้านการพัฒนา (system design แบบละเอียด, sprint plan, testing guide ฉบับเต็ม) ดูเพิ่มเติมได้ที่ `docs/` (ระดับบนของโฟลเดอร์นี้)

## กลุ่มผู้ใช้งานหลัก (Stakeholders)

| กลุ่ม | บทบาท |
|---|---|
| **Super Admin** (Vendor) | ผู้ดูแลระบบ SaaS ทั้งหมด — สร้าง/จัดการ tenant (บริษัทลูกค้า), กำหนดแพ็กเกจ, ติดตามบิล/invoice |
| **Admin / Manager** | ฝ่าย HR หรือผู้จัดการของบริษัทลูกค้า — จัดการพนักงาน/สาขา/กะ, อนุมัติคำขอ, ดูรายงาน |
| **Executive** | ผู้บริหารที่ดูข้อมูลได้ทั้งบริษัทแต่สิทธิ์อนุมัติ/แก้ไขถูกจำกัด (read-only ในหลายจุด) |
| **Dept Head (หัวหน้าแผนก)** | เห็นและอนุมัติได้เฉพาะพนักงานในแผนกที่ตนดูแล |
| **Employee (พนักงาน)** | ใช้แอป LINE LIFF เช็คอิน-เช็คเอาท์ ยื่นคำขอลา/OT/วันหยุด/ลาออก/เอกสาร HR |

## คำนิยามและตัวย่อ (Definitions & Acronyms)

| คำ/ตัวย่อ | ความหมาย |
|---|---|
| **Tenant** | บริษัทลูกค้าหนึ่งรายที่ใช้งานระบบ (หน่วยแยกข้อมูลของ multi-tenant SaaS) |
| **LIFF** | LINE Front-end Framework — เว็บแอปที่เปิดภายในแอป LINE ใช้เป็นแอปฝั่งพนักงาน |
| **Shift** | กะการทำงาน กำหนดเวลาเข้า-ออก, เกณฑ์สาย/ขาด, ค่าปรับ |
| **Weekly-off** | วันหยุดประจำสัปดาห์/เดือนที่พนักงานจองล่วงหน้า |
| **OT** | Overtime — การทำงานล่วงเวลา |
| **Geo-fencing** | การตรวจสอบตำแหน่ง GPS ของพนักงานเทียบกับรัศมีที่กำหนดของสาขา ตอนเช็คอิน |
| **RBAC** | Role-Based Access Control — ระบบสิทธิ์ตามบทบาท |
| **Magic Login** | ลิงก์ล็อกอินอัตโนมัติแบบใช้ครั้งเดียว (จากการแจ้งเตือน LINE) |
