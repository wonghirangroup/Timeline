# Flowchart

แผนภาพลำดับการทำงาน (flow) ของกระบวนการหลักในระบบ อ้างอิงพฤติกรรมจริงของโค้ด

## 1. การเช็คอินของพนักงาน (Auto-detect Shift + Geo-fencing)

```mermaid
flowchart TD
    A[พนักงานกดเช็คอินใน LIFF] --> B{ส่งพิกัด GPS มาไหม}
    B -- ไม่ส่ง --> C[ข้ามขั้นตอนตรวจตำแหน่ง<br/>บันทึก gps_lat/lng = null]
    B -- ส่งมา --> D[คำนวณระยะห่างจากสาขา<br/>haversineMeters]
    D --> E{อยู่ในรัศมีไหม}
    E -- อยู่ในรัศมี --> F[ผ่าน — is_outside_area = false]
    E -- นอกรัศมี --> G{geo_mode ของสาขา}
    G -- WARN --> H[เข้าได้ — ตั้ง is_outside_area = true]
    G -- BLOCK --> I[ปฏิเสธการเช็คอิน]
    C --> J[หากะที่ตรงกับเวลาปัจจุบัน]
    F --> J
    H --> J
    J --> K{มีกะวันนี้ตรงเวลาไหม}
    K -- มี --> L[จับคู่กะวันนี้]
    K -- ไม่มี --> M{มีกะข้ามเที่ยงคืนจากเมื่อวานไหม}
    M -- มี --> N[จับคู่กะเมื่อวาน<br/>fromPreviousDay = true]
    M -- ไม่มี --> O[fallback หากะที่ใกล้เคียงที่สุด]
    L --> P[คำนวณสาย/ขาด<br/>เทียบ late/absent threshold ของกะ]
    N --> P
    O --> P
    P --> Q[บันทึก AttendanceRecord<br/>date = attendanceDate ที่ถูกต้อง]
    Q --> R{เช็คอินวันที่ควรหยุดไหม}
    R -- วันหยุดบริษัท --> S[ตั้ง worked_on_holiday = true<br/>ให้วันชดเชย/พักร้อนอัตโนมัติ]
    R -- จองวันหยุดตัวเอง --> T[ตั้ง worked_on_weekly_off = true<br/>รอ HR resolve]
    R -- ไม่ใช่ --> U[จบขั้นตอน]
```

## 2. การขอลาและอนุมัติ

```mermaid
flowchart TD
    A[พนักงานยื่นคำขอลาผ่าน LIFF] --> B[เลือกประเภทลา + ช่วงวันที่/เวลา]
    B --> C[ระบบคำนวณจำนวนวันที่หัก]
    C --> D{ชนกับคนตำแหน่งเดียวกันไหม}
    D -- ชน --> E[ตั้ง has_conflict = true<br/>ยังสร้างคำขอได้ปกติ]
    D -- ไม่ชน --> F[สร้างคำขอสถานะ PENDING]
    E --> F
    F --> G[ส่งแจ้งเตือน LINE ไปแอดมิน/หัวหน้าแผนก<br/>พร้อมลิงก์ magic-login]
    G --> H[แอดมินกดลิงก์ → auto-login เข้าหน้าอนุมัติ]
    H --> I{อนุมัติหรือปฏิเสธ}
    I -- อนุมัติ --> J{has_conflict?}
    J -- ใช่ --> K[แอดมินเลือกว่าจะหักโควต้าประเภทไหน]
    J -- ไม่ใช่ --> L[หักโควต้าตามประเภทเดิม]
    K --> M[อัปเดตสถานะ APPROVED<br/>บันทึก LeaveBalance.used_days]
    L --> M
    I -- ปฏิเสธ --> N[อัปเดตสถานะ REJECTED + บันทึกเหตุผล]
    M --> O[แจ้งเตือนพนักงานผลการพิจารณา]
    N --> O
```

## 3. การจองวันหยุดประจำสัปดาห์/เดือน

```mermaid
flowchart TD
    A[แอดมินเปิดรอบจอง Weekly-off Period<br/>ต่อสาขา/เดือน + ตั้ง deadline] --> B[ส่งแจ้งเตือน LINE ถึงพนักงานในสาขา<br/>พร้อมลิงก์ LIFF ตรงไปหน้าจอง]
    B --> C[พนักงานเลือกวันหยุด<br/>ตามโหมด WEEKLY หรือ MONTHLY_BATCH]
    C --> D{ครบเงื่อนไขไหม}
    D -- WEEKLY: จองได้หลายวัน/สัปดาห์ --> E[สร้างคำขอ PENDING]
    D -- MONTHLY_BATCH: ต้องจองครบทุกสัปดาห์ --> E
    E --> F[แอดมินอนุมัติ/ปฏิเสธทีละคำขอ<br/>หรืออนุมัติหลายรายการพร้อมกัน]
    F --> G{เลยกำหนด deadline ไหม}
    G -- เลย --> H[ปิดรอบจองอัตโนมัติ — จองเพิ่มไม่ได้]
    G -- ยังไม่เลย --> I[ยังจองเพิ่ม/แก้ไขได้]
```

## 4. คำขอลาออก

```mermaid
flowchart TD
    A[พนักงานยื่นคำขอลาออกผ่าน LIFF<br/>ระบุวันทำงานสุดท้าย + เหตุผล] --> B[สถานะ PENDING<br/>แจ้งเตือนแอดมินทาง LINE]
    B --> C{แอดมินตัดสินใจ}
    C -- อนุมัติ --> D[Employee.status = RESIGNED<br/>ตัดสิทธิ์เช็คอิน/เข้าใช้ LIFF]
    C -- ปฏิเสธ --> E[บันทึกเหตุผล — พนักงานยังคงสถานะเดิม]
```

## 5. Magic Login (Auto-login จากลิงก์แจ้งเตือน LINE)

```mermaid
flowchart TD
    A[ระบบสร้างเหตุการณ์ที่ต้องแจ้งเตือนแอดมิน] --> B[ออก MagicLoginToken<br/>ผูก user_id + next_path, อายุ 2 นาที]
    B --> C[ส่ง Flex Message ทาง LINE<br/>ปุ่มลิงก์ /magic-login?token=xxx]
    C --> D[แอดมินกดลิงก์]
    D --> E{token ยัง valid ไหม}
    E -- valid --> F[claim แบบ atomic — ใช้ได้ครั้งเดียว<br/>ออก access/refresh token จริง]
    F --> G[นำทางไปหน้า next_path ที่ตั้งใจ<br/>เช่น หน้าอนุมัติคำขอนั้นเลย]
    E -- ใช้ไปแล้ว/หมดอายุ --> H{เครื่องนี้มี session ที่ login อยู่แล้วไหม}
    H -- มี --> I[peek next_path จาก token เดิม<br/>พาไปหน้าเดิมโดยไม่ต้อง consume token]
    H -- ไม่มี --> J[แสดง "ลิงก์หมดอายุ" — ไปหน้า login ปกติ]
```

## 6. การขอเอกสาร HR

```mermaid
flowchart TD
    A[พนักงานขอเอกสารผ่าน LIFF<br/>สลิป/หนังสือรับรองเงินเดือน/หนังสือรับรองการทำงาน] --> B[สถานะ PENDING แจ้งเตือนแอดมิน]
    B --> C{แอดมินเลือกวิธีดำเนินการ}
    C -- สร้างในระบบ --> D[กรอกจำนวนเงิน/รายละเอียด<br/>ระบบดึงข้อมูลพนักงาน+บริษัทอัตโนมัติ]
    D --> E[ออกเลขที่เอกสาร + บันทึก snapshot<br/>พิมพ์/บันทึกเป็น PDF ผ่านเบราว์เซอร์]
    C -- อัปโหลดไฟล์แนบ --> F[แนบไฟล์ที่เตรียมไว้นอกระบบ]
    E --> G[กด "แนบไฟล์ + เสร็จ" ปิดคำขอ]
    F --> G
    G --> H[สถานะ COMPLETED แจ้งเตือนพนักงาน]
```
